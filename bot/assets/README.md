# Bot Assets Directory

ضع صورة خلفية الترحيب الخاصة بك هنا بالاسم `welcome-bg.png` أو بأي اسم ومسار تحدده في إعدادات السيرفر عبر الأمر:
`/setwelcome background_path:./assets/welcome-bg.png`

**مواصفات الصورة الموصى بها:**
- الأبعاد: 800 × 360 بكسل (أو نسبة 20:9 أو 16:9).
- الصيغ المدعومة: PNG, JPG, WEBP.
- في حال عدم وجود صورة، سيستخدم البوت تلقائيًا الخلفية المتدرجة الجمالية المحددة بالثيم (Modern Dark, Aurora Blue, Sunset Purple, Cyber Emerald).
